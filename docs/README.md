# docs

Engineering documents of the project. Requirements, the signal interface and
the results live in their own top-level folders (see the main README).

| File | Content |
|---|---|
| [DECISIONS.md](DECISIONS.md) | Design decisions D1… with rationale, status and date; changed only by dated revisions |
| [DEVLOG.md](DEVLOG.md) | Development log, one line per session |
| [mil_to_sil.md](mil_to_sil.md) | Rules that make the MiL logs a valid answer key for the generated code (logging, alignment, number format) |
| [ci.md](ci.md) | What the two CI jobs run and why |
| [requirements_primer.md](requirements_primer.md) | How the requirements are written and verified |

`local/` holds the author's personal material and is **not in the
repository** (git-ignored): milestone reports (`local/milestones/`), learning
guides (`local/guides/`), research notes and the roadmap backlog
(`local/research/`), the teaching report and slides (`local/teaching/`) and the
workflow poster (`local/poster/`).
